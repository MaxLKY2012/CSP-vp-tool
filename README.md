# 福建 CSP 考场回收模拟器

本地运行的 CSP-J/S 第二轮练习工具。Python 标准库后端 + 浏览器界面，无需 npm、数据库、第三方 Python 依赖或网络连接。不是官方 FrC 客户端，不连接考务服务器，不编译、评分或代交 OJ。

## 运行

Windows 安装 **Python 3.10 或更高版本**，双击 `start.bat`。浏览器会自动打开页面。程序内置文件夹选择器，可浏览盘符、子目录、返回上一级或输入路径，无需图形库。也可运行：

```powershell
python app.py
```

Linux / macOS：`sh start.sh`；也可手工填写工作文件夹绝对路径。

ZIP 发布包请先完整解压到有写入权限的目录，再运行启动脚本，不要在压缩包内直接运行。发布包包含源码和网页资源，**不包含 Python 运行环境，也不是免安装 EXE**。

关闭程序：在 **Fujian CSP Simulator** 命令窗口按 **Ctrl+C**，程序会提示 `Exit simulator? Automatic collection will stop. [y/N]:`。输入 `N`、`No` 或直接回车将取消退出，网页服务和定时回收继续运行；输入 `Y` 或 `Yes` 并回车才会停止程序。等待确认期间，网页和自动回收也保持运行。

Windows 启动脚本会打开独立的 Python 窗口，避免出现批处理的“终止批处理操作(Y/N)?”提示。仅关闭浏览器不会停止后台；直接关闭命令窗口或强制结束进程仍会立即终止程序，无法通过 No 撤销。考试中退出会中断正常定时回收，请在收卷完成后退出。无交互终端的自动化运行收到 Ctrl+C 时直接停止，不等待输入。

1. 在 **Settings** 填写完整回收日期、时间（**北京时间 UTC+8**）以及四道题的名称、英文文件名。全部必填，四个英文名不能重复。
2. 输入准考证号，例如 `FJ-00055`，选择工作文件夹，例如 `E:\考场`。选的是准考证号目录的上一级。
3. 点击“开始模拟”。本场考生信息、工作文件夹和 Settings 锁定。
4. 考生自行建立规定目录，用自己的 IDE 作答并保存源码。“检查目录”可核对当前文件是否符合要求，但不会收卷。
5. 截止时间到达后，后台自动回收，自动在默认浏览器打开独立 HTML 报告。也可在主界面点击“打开代码回收报告”。核对四题代码、字节数后，逐题点击“复制代码”到 OJ 提交。
6. 点击“下一场模拟”继续练习，历史回收文件不会删除。

```text
E:\考场\                         ← 工作文件夹
└── FJ-00055\                   ← 准考证号，考生自己创建
    ├── airplane\
    │   └── airplane.cpp
    ├── cashier\
    │   └── cashier.cpp
    ├── dune\
    │   └── dune.cpp
    └── manhattan\
        └── manhattan.cpp
```

以上英文名仅为目录示例，实际以本场 Settings 与试题要求为准。

## 回收规则依据

已核实 [NOI 官网《CCF CSP-J/S 2026 福建省第二轮认证者须知》](https://noi.cn/gs/xw/fj/2026-10-15/940146.shtml)，2026-10-15 发布，2026-10-26 查阅。通用模拟采用其中的目录及回收规范：

- 准考证号的 `FJ` 大写，使用 ASCII 半角 `-`，不是下划线。
- 工作文件夹下以准考证号命名目录，里面为每题建立英文小写同名子目录。
- 每题只收该子目录下同名的 `.cpp` 源程序，后缀小写。不会递归搜索、自动更正命名或回收 `.exe`、`.in`、`.out`、`.cpp.txt` 等。
- 考试开始后不允许修改选手信息；结束后停止作答，核对回收源程序字节数。

该公告的固定考试日期、时长、成绩公示与申诉时间不写死；本工具通过 Settings 指定练习回收时间。中文展示名和英文文件名分开设置。工具仅报告是否成功回收，不将缺失文件直接判为任何分数。

## 快照与存储

`app.py` 所在目录的 `.csp-data\` 保存设置与回收数据（可使用 `--data-dir` 指定其他目录）：

```text
.csp-data\
├── state.json
└── collections\<场次时间-随机编号>\
    ├── snapshot.json       # 原始字节的 Base64 快照，包含四题结果
    ├── manifest.json       # 路径、状态、字节数、SHA-256、规定及实际回收时间
    ├── report.html         # 独立离线报告，自带样式与复制功能
    └── sources\FJ-00055\<英文名>\<英文名>.cpp
```

源文件只读取，不删除、不移动。回收报告来自持久化快照，修改工作目录不会改变已回收代码。UTF-8（含 BOM）和 GB18030/GBK 用于显示，归档保留原始字节、换行和编码。空文件会如实回收并标注 0 字节；无法解码的文件保留下载入口。复制的是源代码文本，不自动删除 `freopen`，请按目标 OJ 要求自行检查。

后台以 0.2 秒间隔检查截止时间，浏览器关闭不影响仍在运行的 Python 程序。**请保持本地程序运行、电脑唤醒，并及时保存代码。**本工具不是操作系统级监考程序，不能阻止外部编辑器修改文件，也无法回收编辑器里尚未保存的内容。

程序关闭或电脑休眠后恢复，如果已经超过截止时间，会执行延迟回收并明确标注。为避免读取明显的超时修改，只接受文件修改时间不晚于截止时间的源码；这无法恢复关机期间的历史文件，也不能防止人为修改系统时间或文件时间戳。读取期间文件变化会标为未回收。四题依次读取，不承诺跨文件的原子时刻快照。

完整快照保存后发生报告导出错误，可以从原快照重新导出，不重新读取考生答案。若在快照落盘前异常中断，会报告错误而不冒充成功回收。回收目录须有可用空间与写权限；状态文件损坏时程序会报错，不会静默清空状态。

本工具额外的本地保护：单源文件上限 10 MiB（**模拟器实现限制，并非官方规定**）；拒绝符号链接和 Windows 联接目录；仅监听 `127.0.0.1`，写入接口校验本机来源和令牌，同一数据目录只允许一个实例。

## 开发与验证

```powershell
python -m unittest discover -s tests -v
node --check web/app.js
python app.py --port 8765 --no-browser
```

测试覆盖必填设置、命名及大小写、错误层级、超时修改、空文件与中文编码、快照不变性、报告转义、读取期间变化、导出失败恢复和本地接口保护。

默认使用空闲端口；`--no-browser` 禁用启动和回收时自动打开浏览器，便于测试，页面里的报告链接仍可用。

## 打包发布

运行 `python tools/build_release.py`，在 `dist\` 生成带日期的 ZIP 及 SHA-256 校验文件。按明确的文件清单打包，不包含本地设置、考生答卷、回收报告、测试数据、缓存和截图。
